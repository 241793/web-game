# 战地前线 - Battlefield Front

一个基于 three.js 的网页版战地类第一人称射击游戏。
 - 战地：https://241793.github.io/web-game/zhandi
 - 伪泰拉瑞亚：https://241793.github.io/web-game/tlry


## 运行方式

由于使用了 ES Modules，需要通过 HTTP 服务器运行：

```bash
# 方法1: Python
python -m http.server 8080

# 方法2: Node.js
npx http-server -p 8080

# 然后在浏览器打开
# http://localhost:8080
```

## 游戏特性

### 核心玩法
- 第一人称射击（FPS）
- 团队死斗 + 据点占领模式
- 5个可占领据点（A/B/C/D/E）
- 击杀得分 + 据点持续得分
- 爆炸击杀、友方载具击杀和玩家助攻会纳入结算
- 15分钟比赛时限、1000分上限或征服票数耗尽

### 4大兵种
| 兵种 | 主武器 | 副武器 | 特色 |
|------|--------|--------|------|
| 突击兵 | M416 / AK-12 / SCAR-H / M249 | P226 手枪 | 全能型，高血量 |
| 医疗兵 | MP5 冲锋枪 | P226 手枪 | 快速移动支援 |
| 工程兵 | M870 霰弹枪 | RPG-7 火箭筒 | 反载具专家 |
| 狙击手 | L96 / M40A5 / SKS | MP443 手枪 | 远距离爆头 |

- 部署前可为支持的兵种选择主武器，阵亡重生后会保留当前选择。

### 武器系统
- 多类武器：突击步枪、冲锋枪、霰弹枪、狙击步枪、轻机枪、精准射手步枪、手枪、火箭筒
- 射击手感：后坐力、枪口闪光、弹道追踪、命中标记
- 右键瞄准（狙击枪8倍镜）
- 弹药管理与换弹
- 手雷投掷（G键）
- 爆炸范围伤害

### 角色动作
- 站立 / 蹲下（Ctrl）/ 趴下（Z）
- 跳跃（空格）
- 冲刺（Shift）
- 视角晃动与武器晃动

### 敌我区分
- 我方：蓝色制服 + 蓝色头顶标记 + 蓝色臂章
- 敌方：红色制服 + 红色头顶标记 + 红色臂章
- 敌方交战时标记闪烁

### 载具系统
| 载具 | 装甲 | 速度 | 武器 | 座位 |
|------|------|------|------|------|
| 战术吉普车 | 300 | 30 m/s | 无 | 3 |
| 主战坦克 | 800 | 15 m/s | 主炮(200伤害) | 2 |
| 装甲运兵车 | 500 | 22 m/s | 机枪(40伤害) | 4 |
| 武装直升机 | 400 | 40 m/s | 机炮(60伤害) | 2 |

- 按 F 进入/离开载具
- 按 V 切换第一/第三人称视角
- 按 C 切换载具座位
- 驾驶员控制移动
- 坦克/装甲车/直升机可控制炮塔开火
- 坦克炮弹产生范围爆炸伤害和弹坑痕迹
- 直升机可飞行（Space上升，Shift下降）
- 载具可被摧毁并爆炸

### AI系统
- 24个AI士兵（每队12个）
- 状态机：巡逻 / 交战 / 撤退
- 视线检测与障碍物遮挡
- 距离保持与侧移走位
- 低血量撤退
- 自动换弹与重生

### 地图
- 400x400 起伏地形
- 建筑群、围墙、沙袋掩体
- 木箱、混凝土路障
- 集装箱堆场
- 树木植被
- 道路网络
- 全部障碍物带碰撞检测，不会穿模

### 音效（Web Audio API 程序化生成）
- 各武器独特枪声
- 换弹声
- 爆炸声
- 脚步声
- 载具引擎声
- 命中标记音
- UI音效
- 3D空间化音频

### UI/HUD
- 动态准星（移动扩散、瞄准收缩）
- 血量/护甲条
- 弹药显示
- 击杀提示
- 小地图（实时敌我位置）
- 据点进度
- 比分与计时
- 伤害指示器
- 得分板（Tab键）
- 暂停菜单

## 技术栈

- **渲染引擎**: Three.js (r160)
- **架构**: ES Modules + ImportMap
- **音频**: Web Audio API（程序化合成，无外部音频文件）
- **碰撞**: AABB 分轴解析 + Raycaster 射线检测
- **AI**: 有限状态机 + 视线检测
- **模型**: Three.js 基础几何体程序化构建
